# Padel Coach web app

React 19 + TypeScript single-page app built with Vite. See the [root README](../README.md) for the full
architecture and setup.

```bash
npm install
npm run dev     # http://localhost:5173
npm run lint
npm run build   # type-check (tsc -b) + production bundle
```

Environment (`.env.local`): `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_API_URL`.
